# 連環賞小管家｜澳門消費連環賞 2026

手機及桌面均適用的個人記錄 APP，用來記錄各個合資格支付錢包抽到的優惠券、核銷狀態及活動週次。這是手動記錄工具，不是官方活動平台。

## APP

https://wuchiwa.github.io/macau-rewards-2026/

## 使用說明

### 1. 註冊或登入

1. 開啟上方 APP 網址。
2. 點擊畫面右上方的登入入口。
3. 首次使用可註冊帳戶，按頁面提示輸入電郵及密碼；已有帳戶則直接登入。
4. 登入後，APP 會使用你的帳戶讀取及同步雲端記錄。建議在不同裝置使用同一帳戶，方便查看同一份記錄。

### 2. 新增及選擇錢包

1. 在錢包區選擇已建立的錢包；需要時可新增錢包。
2. 可為錢包記錄持有人，以便分辨自己或家人的支付錢包。
3. 支援 MPay、支付寶、中銀、工銀、豐付寶、廣發、LusoPay、UePay，同一支付平台可建立多個錢包。

### 3. 記錄抽獎結果

1. 選擇本次抽獎所使用的錢包。
2. 按實際抽到的結果選擇優惠券類型及面額。
3. 確認結果後記錄。優惠券分為黃色「商戶滿減券」及藍色「消費禮遇券」，面額為 MOP 10、20、50、100、200。
4. 每個錢包每週最多記錄 3 張優惠券；請按實際結果記錄，不要把同一張券重複加入。

### 4. 查看記錄及核銷

- 查看本週抽獎次數、優惠券總額及本週未核銷優惠券。
- 在歷史記錄中查看各週及各錢包的優惠券。
- 使用核銷功能標記已使用的優惠券；核銷前請確認所選範圍及券的狀態。
- 「所需消費金額」按未核銷優惠券面額總和乘以 3 作估算，實際使用條件以官方券面及活動條款為準。

## 數據儲存與私隱

**APP 的個人錢包及優惠券記錄以 Supabase 雲端資料庫作為登入後的主要儲存與同步來源。個別使用者的錢包、優惠券及核銷記錄只應由該帳戶的使用者讀取；其他使用者不能讀取你的個人記錄。**

- APP 透過登入帳戶識別使用者，資料存取必須由 Supabase Row Level Security（RLS）政策限制為該使用者自己的資料。
- **例外是全體使用者的彙總統計**：為展示整體活動統計而提供的彙總數字可能供所有使用者查看；這不代表其他使用者可查看你的個別錢包或優惠券記錄。
- 如在未登入狀態下先行記錄，部分資料可能暫存在當前裝置的本機，登入後再同步。未確認已同步前，請不要清除瀏覽器資料或更換裝置。
- 雲端資料的私隱隔離依賴 Supabase 的 RLS 及資料庫政策正確設定；部署者應定期確認政策有效。
- 前端使用 Supabase Project URL 及 Publishable key。Publishable key 出現在瀏覽器端屬正常設計；切勿把 Supabase Secret 或 `service_role` key 放進前端。

## 功能

- 同一帳戶可在手機、平板及電腦登入並同步記錄。
- 支援不同錢包持有人及同一平台的多個錢包。
- 按活動週次記錄各錢包的抽獎結果；每個錢包每週最多記錄 3 張優惠券。
- 查看優惠券歷史、週次及核銷狀態。
- 不要求輸入消費金額、商戶或消費類型。
- 不記錄長者／殘疾人士卡的 MOP 500 即時立減優惠。

## 活動日期與規則提醒

- 活動記錄週期：2026 年 10 月 9 日至 12 月 17 日，共 10 週；每週由星期五至星期四。
- 合資格消費條件及抽獎次數請以官方最新活動條款為準。
- 優惠券使用門檻按券面額的 3 倍計算；實際可用日期、適用商戶及其他限制以官方券面和活動條款為準。

## 部署與設定

1. 在 Supabase 專案套用 `schema.sql` 前，先確認現有資料表及結構；若資料表已存在，不要盲目重建。
2. 在 Supabase Auth 設定電郵登入，並按需要設定註冊及電郵驗證。
3. 在 GitHub 專案 Settings → Pages → Deploy from a branch，選擇 `main` 分支及 `/(root)`。
4. 開啟 APP 網址並登入，或註冊新帳戶。

## 注意事項

- APP 只作手動記錄，不會連接官方錢包、自動讀取交易，亦不會核實商戶或消費是否符合資格。
- 本週未核銷優惠券的所需消費提示，是未核銷券面額總和乘以 3 的估算值，不代表官方核銷保證。
- 如登入／註冊失敗，請先確認 Supabase Auth 設定、電郵驗證狀態及網絡連線。
