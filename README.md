# 澳門消費連環賞 2026 記錄 APP V2

Responsive web app for tracking wallets, spending, and reward claims. See `schema.sql` for Supabase setup and `index.html` for the app.

## Setup
1. Run `schema.sql` in your Supabase SQL Editor.
2. Enable Supabase Email authentication.
3. Publish this repository with GitHub Pages (Settings → Pages → Deploy from branch → `main` → `/(root)`).
4. Open the site and enter your Supabase Project URL and Publishable key.

Never put a Supabase secret or service-role key in the browser.
